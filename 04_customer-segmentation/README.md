# 👥 Customer Segmentation — Internship Project

An unsupervised machine learning project that segments customers into distinct groups based on their behavior and demographics, built during my internship at **Arch Technologies**.

## 💡 Problem Statement
Businesses struggle to understand their diverse customer base. This project automatically groups customers into meaningful segments, enabling targeted marketing and personalized experiences.

## 🧠 Approach
- **Algorithm:** K-Means Clustering
- **Optimal K:** Determined using the Elbow Method
- **Features used:** Customer demographics and purchasing behavior
- **Output:** Interactive dashboard showing segment profiles

## 📁 Project Files
| File | Description |
|------|-------------|
| `customer_segmentation.py` | Complete ML pipeline — data processing, clustering, evaluation |
| `customer_segmentation_dashboard.html` | Interactive visualization dashboard |

## 🛠️ Tech Stack
- Python 3.x
- Scikit-learn (K-Means Clustering)
- Pandas, NumPy
- Matplotlib, Seaborn, Plotly
- HTML/CSS (interactive dashboard)

## ⚙️ How to Run

### 1. Install dependencies
```bash
pip install scikit-learn pandas numpy matplotlib seaborn plotly
```

### 2. Run segmentation
```bash
python customer_segmentation.py
```

### 3. View dashboard
Open `customer_segmentation_dashboard.html` in any browser.

## 📊 Output
- Customer segments with distinct profiles
- Cluster visualization (scatter plots)
- Segment size and composition charts
- Exportable CSV with segment labels

## 🎯 Key Concepts Demonstrated
- Unsupervised machine learning
- K-Means clustering

- Data preprocessing and feature scaling
